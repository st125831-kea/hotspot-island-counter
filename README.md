# Hotspot Island Counter

Bilingual Thai/English browser tool for classifying VIIRS hotspot points into:

- Sumatra
- Borneo
- Other Indonesian Islands
- Other Countries

## Features
- Reads Excel files (`.xlsx` / `.xls`) with `LATITUDE`, `LONGITUDE`, and `CT_EN`
- Processes files locally in the browser
- Separates Borneo hotspots by country
- Shows total hotspots, Sumatra + Borneo, and Indonesia (all islands)
- Lists every country found under Other Countries
- Exports classified CSV and Excel
- Responsive for desktop and mobile

## Privacy
The selected Excel file is processed locally in the browser and is not uploaded to a server.
